# DJS CodeStars — Website Redesign

A modern, responsive redesign of the DJS CodeStars website built with React and Vite.

## 🚀 Features

- Responsive design
- React Router navigation
- Interactive developer terminal
- Events section
- About section
- Contact form with frontend validation
- Mobile navigation menu
- Active navigation states
- Custom 404 page
- CSS animations and hover interactions

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- React Router
- Lucide React
- CSS
